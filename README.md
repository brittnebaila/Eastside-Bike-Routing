# Eastside Bike Routing

A GIS + software engineering project exploring safer and more useful bicycle routing on the Eastside using public city GIS data.

## Current Focus
- Learning QGIS
- Exploring City of Bellevue trail data
- Practicing feature selection and attribute queries

## Planned Features
- Bike-friendly route comparison
- Elevation and grade analysis
- Trail and road surface information
- Integration with web mapping tools such as Leaflet
